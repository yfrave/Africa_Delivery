# Failure Mode and Effects Analysis

Система: MVP Africa Delivery  
Дата: 2026-10-03  
Версия: 1.0

Шкала: S - тяжесть, O - вероятность, D - сложность обнаружения, 1-10.  
RPN = S x O x D. Значение выше 100 требует немедленной меры до запуска.
