# Africa Delivery

Архитектурное решение для запуска маркетплейса в Нигерии и Кении к 15 октября 2026 года.

Основной вариант MVP - модульный монолит на Go, PostgreSQL, кеш каталога, очередь фоновых задач и партнёрские интеграции. Решение рассчитано на восемь недель, шесть контракторов и инфраструктурный бюджет до 5 000 долларов в месяц.

## Сквозные решения

- Срок и бюджет важнее раннего перехода к микросервисам.
- Платежи и логистика на этапе MVP подключаются через партнёров.
- Идентифицирующие данные разделяются по стране субъекта.
- Архитектура допускает выделение сервисов без переписывания модулей.
- Показатели доступности задаются отдельно для каталога, оплаты и уведомлений.

## Допущения

- Точные требования по трансграничной передаче данных подтвердят местные юристы после запуска.
- До подтверждения действует консервативное правило: данные граждан Нигерии остаются в Нигерии.
- Входные письма содержат противоречия. Их разрешение зафиксировано в [реестре противоречий](Task1/contradictions.md).
