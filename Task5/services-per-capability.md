# Сервисы по возможностям

Под «сервисом» здесь понимается модуль приложения или внешний продукт. В MVP собственные модули выпускаются одним приложением по ADR-001.

| Capability | Продукт / сервис | Владелец | Внешняя зависимость |
| --- | --- | --- | --- |
| Каталог | модуль каталога, PostgreSQL, S3/CDN | разработчик каталога | AWS |
| Поиск и просмотр | SQL-поиск, кеш PWA/CDN | разработчик каталога | CDN |
| Корзина и заказ | модуль заказа | разработчик ядра | профиль страны |
| Приём оплаты | модуль оплаты + адаптеры | разработчик оплаты | M-Pesa, Flutterwave |
| Сверка и выплата | журнал платежей, отчёт сверки | финансы + разработчик оплаты | отчёты провайдера |
| Онбординг продавца | модуль продавцов, WhatsApp-процесс | операционный менеджер | WhatsApp Business API, KYC |
| Управление товаром | команды WhatsApp + back office | оператор каталога | WhatsApp Business API |
| Передача в доставку | модуль доставки | менеджер операций | Sendbox, Sendy |
| Статус доставки | webhook партнёра, статус заказа | менеджер операций | Sendbox, Sendy |
| Уведомления | очередь и адаптеры каналов | разработчик уведомлений | SMS, WhatsApp |
| Согласия | модуль согласий, хранилище страны | владелец данных | местный юрист |
| Модерация | базовый back office | операционный менеджер | KYC-партнёр |
| Аналитика CEO | обезличенные SQL-представления, панель | аналитик/CEO | управляемая панель |
| Наблюдаемость | OpenTelemetry, Prometheus, Grafana, Loki, Tempo | DevOps/SRE | AWS |
| Профиль Нигерии | Profile API и местная БД | владелец данных | провайдер Лагоса |

Источник: capability map, ADR-001, ADR-003 и артефакт 4.
